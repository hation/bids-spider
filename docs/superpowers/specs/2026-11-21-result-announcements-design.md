# 中标/废标公告采集与结果追踪 — 设计文档

- 日期：2026-11-21
- 状态：待审阅
- 背景文档：`docs/省份采集站点清单.md`

## 1. 需求与目标

用户需要从"只知道哪些项目在招标"升级为掌握项目全生命周期，提前做准备：

| 想知道的 | 对应公告类型 | 现状 |
|---|---|---|
| 哪些项目在招标 | 招标公告 | 已在采集（29 省） |
| 哪些招标结束、哪个公司中标 | 中标公告 | 部分省混合列表顺带含，未系统区分 |
| 哪些项目流标 | 废标公告 | 基本未采集 |

目标：独立采集各省中标/废标公告，按 `announce_type` 标记入库，提供独立查询命令查看三类公告；历史数据回填分类。

## 2. 已确认的决策

- **方案 A**：中标/废标独立采集，不按项目配对（不关联回原招标公告）。
- **中标单位提取**：规则 + 正则（不用 LLM 精读）。
- **历史数据回填**：全部存量 `tenders` 按标题分类标记。
- **范围**：档1（北京区级中标/废标、天津结果公告）+ 档2 中可确认 URL 的省（重庆/山东/贵州）；云南/浙江/青海/安徽待用户协助确认。
- **输出**：独立查询命令 `scripts/query_results.py`；汇总 Excel 增加类型/中标单位/中标金额列。
- **不纳入** `analyze_opportunities.py`（机会分析定位是找新招标机会，结果追踪各管各的）。
- **不做**：项目配对、LLM 精读结果公告、独立 HTML 报告。

## 3. 数据模型

`Tender` dataclass 与 ES `tenders` 索引新增 3 个字段（`ensure_index` 的 put_mapping 自动补 mapping）：

| 字段 | ES 类型 | 含义 |
|---|---|---|
| `announce_type` | keyword | `招标公告` / `中标公告` / `废标公告` |
| `win_company` | keyword | 中标单位名称（仅中标公告有值） |
| `win_amount_wan` | double | 中标金额（万元，仅中标公告有值） |

### 类型判定规则（标题关键词，优先级从高到低）

1. 标题含 `废标/流标/终止/失败` → `废标公告`
2. 标题含 `中标/成交/结果` → `中标公告`
3. 其余 → `招标公告`

### 中标单位/金额提取（正文正则，复用 `_enrich_meta` 模式）

- 单位关键词：`中标供应商|中标单位|成交供应商|成交单位|中标人|成交人` + 分隔符 + 公司名称
- 金额：`中标金额[:：]X(万元|元)`，复用 `extract_money` 逻辑
- 提取率受各省表述差异影响，存在漏提，属可接受局限

### 两路来源统一走该规则

- 新增专门栏目（北京区级、天津、重庆、山东、贵州等）→ 列表本身明确类型，直接标记，不靠猜
- 现有混合列表（北京市级、河北、黑龙江等 11 省）→ 按标题关键词分类

## 4. 采集接入（新增"结果公告采集器"）

**架构**：不改造现有 29 个爬虫。新增独立、按省配置驱动的采集模块；两路采集都进同一 `tenders` 索引，靠 `announce_type` 区分。

|---|---|---|---|

### 每日流程接入

- `fast_run.py` 新增模式（如 `results <date> --regions ...`）按日期抓结果公告。
- 并入每日 `summarize` 汇总：Excel 增加"公告类型/中标单位/中标金额"列，三类公告同一表并列，不改变现有日报结构。
- 采集要点沿用项目规则：按日期归档 `output/<date>/`、jsonl 汇总、`--no-summary` 并行批跑纪律。

## 5. 历史数据回填

- 新增回填脚本：扫描全部 `tenders`，按标题分类标记 `announce_type`；标题含"中标/成交"的再提取 `win_company` / `win_amount_wan`。
- 幂等：已标记且标题未变的不重复处理；可重复运行。

## 6. 独立查询命令 `scripts/query_results.py`

仿 `query_opportunities.py` 模式，从 ES 查询（不爬网站）：

```bash
.venv/bin/python scripts/query_results.py [起] [止]                # 默认近 30 天，全类型
.venv/bin/python scripts/query_results.py 2026-11-01 2026-11-21 --regions beijing,shandong
.venv/bin/python scripts/query_results.py --types 中标,废标        # 只看中标/废标
.venv/bin/python scripts/query_results.py --kw 服务器,存储          # 关键词过滤
.venv/bin/python scripts/query_results.py --company XX公司          # 查某公司近期中标
```

查询维度：时间范围（`release_date`）、地区（`--regions`）、公告类型（`--types`）、关键词（`--kw`，命中标题/正文）、中标单位（`--company`）。

输出（按日期归档，仿窗口期查询模式）：
- `output/结果查询/<时间戳>_<起>_<止>/查询结果.md`：分三组——**招标中**（按投标截止紧迫度排序）、**已中标**（中标单位+金额，按金额降序）、**已流标**（废标公告）
- `查询结果.xlsx`：全字段明细（公告类型/中标单位/中标金额/链接/金额/截止时间等）

## 8. 成功标准

1. 新增字段可写入并查询 ES（`announce_type`/`win_company`/`win_amount_wan`）
2. 档1 三项 + 重庆/山东/贵州结果公告能按日期抓取入库并正确标记类型
3. 存量数据回填后，按类型查询结果合理（中标/废标分类准确率可抽查）

5. 每日汇总 Excel 含三类公告并列
